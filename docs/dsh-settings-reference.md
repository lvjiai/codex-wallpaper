# DSH 壁纸引擎设置参考

记录自 2026-11-13 提供的九张截图。截图中的数值是参考配置。

| 页面 | 截图中的设置 |
| --- | --- |
| 壁纸库 | 当前壁纸、选择、暂停、静音、清除和刷新。预览卡片可多选，支持名称、内容分级和类型筛选。切换使用交叉淡化，标准约 1800 ms，另有快和慢。轮播组可新建、编辑、删除，示例为顺序、每 30 分钟轮换。自定义壁纸可设置存储位置和官方资源路径，支持本地图片、MP4 和 Wallpaper Engine 项目。 |
| 外观 | 主题随壁纸、边框、主题预设及导入导出。玻璃颜色、透明度、雾化、保真度和自定义选择器。思考块、标题栏、侧栏可独立调节，左右侧栏可统一或逐角设圆角。另有全局配色、光标颜色和字体。 |
| 播放 | 模糊、亮度、对比度、饱和度、水平和垂直位置、缩放、透明度、暗化、倍速、帧率上限、适配、水平翻转、音量和音轨。截图为 4K 60fps H.264，覆盖、1 倍速、帧率无限制、暗化 45%、静音。 |
| 系统 | Edge 兼容、适配目标、最小化或切页暂停、电池模式暂停、缓存目录和重置。 |
| 扩展 | 自定义会话头像、点击和拖尾效果、3D 视差。 |
| 关于 | 截图展示页签。 |

本轮范围为侧栏入口、带本地预览的选择卡片、壁纸组、轮换间隔、顺序和切换效果。预览取 Wallpaper Engine 项目自带图片或动图。场景壁纸应用后由 Wallpaper Engine 实时渲染。
